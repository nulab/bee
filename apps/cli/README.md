# bee

Bring [Backlog](https://backlog.com/) to your command line.

## Install

```sh
npm install -g @nulab/bee
```

## Quick Start

Authenticate with your Backlog space:

```sh
bee auth login
```

Then start using bee:

```sh
bee issue list
bee issue view PROJECT-123
bee project list
```
